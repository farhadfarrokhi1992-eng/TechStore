
# TechStore

An AI-powered e-commerce platform for digital products.

## Project Overview

TechStore is a full-stack e-commerce project designed to sell digital products such as laptops, accessories, and computer components.

The platform will include an AI customer support agent and workflow automation.

## Planned Features

- Product catalog and categories
- Product search
- Shopping cart
- User authentication
- Order management
- Admin dashboard
- AI customer support agent
- Order tracking automation
- RAG-based product knowledge system

## Technology Stack

- Frontend: HTML, CSS, JavaScript, React
- Backend: Python, FastAPI
- Database: PostgreSQL
- Automation: n8n
- AI: LLM, RAG, Vector Database
- Version Control: Git and GitHub
